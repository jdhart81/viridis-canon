# One selected runtime source, immutable history

The selected prospective source is `runtime/`. Its proposed Git
namespace is `00_lab_infrastructure/gates/standalone_pdf_release/runtime/`.
The nineteen source modules and both worker source admissions bind that exact
namespace. V012 semantic labels, installed-path requirements, historical
bindings and existing failed-health provenance remain unchanged. No
`future_runtime_v001` through `future_runtime_v013` directory remains in HEAD.

This is source consolidation, not installation or runtime admission. The
existing v2 digest controller/helper remains inside the selected source with
its original science, certificate, source-review, journal and public-readback
requirements. The independent reviewed installation and bounded sandbox
rehearsal gates remain required. No V013 behavior is promoted or repaired.

`RUNTIME_HISTORY.json` preserves byte-identical version rows for all 505 original v001–v012 merge/tree/blob
rows and adds the 59 exact v013 rows at their existing merge. The unselected
v001–v012 and v013 directories live in Git history. Annotated tags
`pdf-runtime-v001` through `pdf-runtime-v012` were pushed and their remote
objects and peeled original merge targets verified. The top-level current
source path and tag metadata record that result; historical version/file rows
remain unchanged. V013 remains an unselected
historical successor, including its original tests and diagnostics.

`common/runtime_history.py` supplies exact local Git bytes to the retained
predecessor tests. It checks the version tree, commit path, regular blob mode
and blob identity. It never extracts an old runtime, imports historical source
as a module, starts network traffic or supplies an admission result. Existing
tests may still execute their original scoped AST fixtures in their original
synthetic contexts. Only their storage lookup changed; the expected hashes and
functional assertions remain intact.

The selected runtime retains its original 387 tests and prospective behavior
regressions. CI runs that functional
suite once per Python version and separately checks all 564 historical blob
bindings. It does not re-run thirteen largely duplicated runtime trees. The
source consolidation does not claim that unselected V013 behavior passed, or
that source tests establish a successful production health check.

`common/` contains the historical test-source reader and the exact hash-bound
stable-input reader. The runtime, source proof, installer and both worker
bootstraps bind the shared input reader separately from the fixed nineteen
module rows. No ambient common-module import supplies its implementation.

Installed Core directories remain untouched. The source rename preserves the
fixed `_ZENODO_DEPOSITS/standalone_pdf_runtime_v012` target and the installer's
absent-target guard. It does not make the already-existing target installable,
retire the live predecessor chain, change the adoption baseline, or supply a
runtime admission result. In-place adoption needs a separately reviewed plan.
Bulk evidence archival has its own exact archive/index/removal receipts; this
source layout document does not certify that operation.
