# Current nightly manuscript access format

This source adds a separate access package for an unchanged ordinary nightly
minimal note. It does not activate a publisher or change scientific admission.
The audited PR110 source and every historical99/130 physical source binding stay
unchanged. Both successor publishers remain quarantined.

The current profile is `VRS-DIGEST-ARCHIVAL-PDF-PACKAGING-PROFILE-1`: exactly the
prior18 digest modules plus `nightly_manuscript_access.py` and
`nightly_manuscript_checkpoint.py`, with the same one shared input dependency.
The only publication default remains `digest: invoke_digest_v2.py`. Historical
17/19 module schemas, source-review flags and installation inventories retain
their original meaning.

The profile's closed `note_preparation` nomination selects exactly the new
checkpoint facade and six entrypoints: `source_for_cycle`, `stage_checkpoint`,
`review_checkpoint`, `prepare_access`, `new_note_specs`, and
`stage_weekly_package`. `packaging_runtime.note_preparation(root, entrypoint,
*args, **kwargs)` resolves that nomination and enters the genuine measured source
session before loading/calling it. A caller cannot choose a module or callable.

The sequence is the ordinary certified/current/parity-qualified source selection,
immutable minimal-note staging, a separate later current review, and actual old
default `phase7_audit_policy` publication-binding admission. New source does not
change those consumers, expand the historical56 population, or issue a
certificate. A new access validator freshly compiles the closed original source
bytes into private modules and executes that same default reader on every
validation, including a second read after deriving access bytes. Saved PASS
objects, ambient canonical modules and bytecode cannot replace that reader.
All51 frozen source hashes already occur in the historical130-source scope.
The49 gate modules retain their original gate paths; the two producer helpers
retain their exact `reports/.../weekly-source-adoption-v001` origins. A closed
per-helper origin map is used both for loading and manifest records. A relocated
copy, missing original, symlink, changed hash or exit-time race is refused.

The scientific base stays at its own immutable path. A distinct
`VRS-NIGHTLY-ARCHIVAL-MANUSCRIPT-ACCESS-1` manifest identifies that predecessor's
exact manifest and publication binding. The access package copies scientific,
claim, metadata, certificate, candidate and statement uploads byte-for-byte.
Its new `SCOPE_EVIDENCE.zip` preserves every original member's path and bytes
and adds exactly `historical/ORIGINAL_paper.pdf`; the existing
`historical/ORIGINAL_paper.tex` is retained. The old archive itself remains
unchanged at the scientific predecessor path.

The scoped note's existing `paper.pdf` remains exact. The historical PDF must
match a separate `Run-NNN-Historical-Paper.pdf` upload. Its isolated render input
is `paper.tex` containing exactly the original archived TeX bytes; this render-only
basename satisfies the existing observer ABI without renaming the archived
source. The old pinned binary/cache/source/PDF observer validates the new render
independently. This first closed format supports standalone TeX plus the exact
pinned cache. A manuscript with unbound local file dependencies or dynamic input
stays HOLD; its source is never edited to compile. The supported syntax is a
fixed article class, seven fixed cache packages with closed options, fixed
markup environments and control words. Internal input aliases, category or
macro construction, translation escapes and unknown commands are refused.
Escaped control symbols and line breaks are tokenized as such. A corrected R3 manuscript or
a merely paired old PDF cannot replace the original manuscript/render evidence.

The access binding is a separate byte binding, with `certifies: false` and
`publication_authorized: false`. The historical role is
`UNCERTIFIED_HISTORICAL_MANUSCRIPT` and remains entirely uncertified. This format
does not assert that the original scientific binding covers a modified archive,
or that render correspondence is a full visual/scientific review. Operational
full-PDF review and existing publication authority remain separate prerequisites.

The current digest default loads the nominated exact access consumer and
reconsumes the scientific predecessor. Its manifest records both manuscript
roles, and its upload set has Run-specific scoped and historical PDFs. The
unchanged recursive standalone-PDF gate checks same-stem PDFs in nested archives
and exact separate top-level copies. Existing strict readback downloads and
checks every uploaded file, including both PDFs, by size, SHA256 and MD5.

Portable tests use explicitly simulated provider/trust/platform/render/cache
DATA with valid PDF files. Actual original validator bodies execute; no
assess/evaluate/publication-binding PASS result is mocked. Test trust constants
and platform paths are isolated from production and do not establish real Mac
renderer execution, real Comparator certification, or scientific admission.
Production still requires the genuine pinned Mac binary/cache, actual current
source/certificate/parity/authority, later full-PDF review, exact-head independent
review, Justin merge and an S4 installation/rollback receipt. No production
activation or rendering is performed by these source tests.

The default access reader also requires the exact currently active complete
source session. A standalone profile/nomination, even with matching local file
hashes, cannot authorize loading an access consumer. The session binds both
legitimate private-bootstrap and canonical runtime instances, resets their
context on exit and revalidates the closure. Historical direct consumers retain
their prior behavior.

Coverage is partitioned explicitly. Smaller tests exercise the real old
scientific default path through PB and access, and separate source contract
tests cover facade/session boundaries. The complete-source regression below
joins all eleven historical predecessors, alias/timezone/transient checks, the
original99/130 closure and the current20+1 session with all six actual facade
operations, the unchanged recursive PDF gate and exact simulated public
readbacks. It uses declared synthetic trust/platform/render/provider DATA;
a genuine operational source-session and production readback remain separate.
Unscoped normal default dispatch is tested to HOLD.

The complete-source integration regression is an explicit separate command:
`python3 -B -m unittest discover -s 00_lab_infrastructure/gates/standalone_pdf_release/runtime/tests -p 'w42_complete_default_route_test.py' -v`.
Its filename deliberately keeps this expensive, fresh-validation route out of
the ordinary `test_*.py` matrix. The workflow selects the normal route and the
three negative controls in separate ten-minute jobs on both Python versions.
The required aggregate depends on all four complete-source jobs and both
ordinary matrix jobs; a failed, canceled or skipped job cannot satisfy it.
No validation result is cached to meet that time bound.
