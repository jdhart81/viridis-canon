# Methods Digest public projection

Methods Digests use a separate `methods_digests` catalog population. A group is a collection with `certifies: false`, no aggregate certificate, and no source/spine admission. Its notes share the group's DOI and carry `LISTED_NOTE_SCOPE_ONLY`, each note's certificate/binding hashes, exact frozen scientific statement fields (including hypotheses, ambient context and model-fidelity tags), foundation basis, and obtained semantic/nonvacuity labels. Historical claim-map `evidence_class` and `scope_status` fields are omitted from the public scope text because fresh registration and the current semantic labels determine status; the raw bound evidence is untouched. Optional enrichment remains non-blocking under GAME_PLAN's “SIMPLIFICATION — weekly push restored — 2026-10-07.”

`scripts/generate_public_index.py` calls the unchanged default `methods_digest_registration.require_registration` for every named group. It then compares the complete named SSOT cohort to `entity_rows` from that fresh result. A missing, changed, orphaned or held member holds the cohort. Bound note metadata titles remain exact. Groups and notes are rendered under `methods_digests`; neither is inserted into generic `CANON_INDEX.entries` or counted as a newly admitted repository source.

The generated `METHODS_DIGESTS.json` packet has exactly `standard: PUBLIC_METHODS_DIGEST_POINTERS_1` and `methods_digests`. After actual strict publication and preserving SSOT registration, the operator may snapshot that exact public packet into the repository and set `catalog/config.json`'s `methods_digest_joins` to its tree-relative path plus SHA-256. `canon_core.methods_digests` verifies this closed pointer projection. It is a catalog adapter, not proof acceptance. Pointers and hashes alone cannot admit sources; the canonical current consumer still owns admission.

Existing `publication_joins` and its unique-record schema remain unchanged. Digest records cannot collide with generic publication record/entity IDs. Children share the parent DOI within this separate shape. The new catalog field defaults to an empty list; this change includes no fabricated publication record or future DOI. The existing catalog's source records, module labels, statistics and publication joins remain byte-identical after removing only the new field and recomputed catalog digest.

For production rendering, use the existing reviewed runtime source-session/import closure, followed by this merged renderer source and its two ordinary projection modules. The renderer accepts only its byte-identical registrar from this checkout or the scanned tree's installed gate directory. This does not install or select the checkout's source-only pypdf version. Keep the approved deployed historical parser and protected gate sources unchanged. All original proof, intake, registrar and runtime modules are untouched in this PR.

This patch performs no public write, registration, runtime install, policy change, scheduler update or catalog deployment. Those steps remain with the authorized production controller after actual public and SSOT readback.
