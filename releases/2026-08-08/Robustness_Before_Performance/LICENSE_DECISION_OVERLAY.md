# Versioned rights-metadata overlay

The sealed scientific artifacts and historical rights-held review remain
preserved unchanged in provenance. On 8 August 2026, Justin D. Hart delegated
responsibility to put the relevant Viridis Research submission packages in
order and make the best release decisions as head scientist and engineer.
Under that direction, this release overlay assigns CC BY 4.0.

Rationale: this is an open research package whose value depends on transparent
inspection, reproduction, critique, and extension. CC BY 4.0 provides a clear
attribution requirement and aligns it with the other weekly Viridis research
records.

This overlay changes rights and release metadata only. It does not change the
paper, Lean source, theorem statements, software implementation, test
fixtures, or scientific claims. It also does not assert security certification,
empirical effectiveness, legitimate execution authority, public canon
admission, or Intelligence Bound spine status.
