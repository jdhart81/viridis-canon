## Authorization and recovery boundary

This report authorizes no future action. Any timeout or unknown draft/publish outcome requires read-only reconciliation before another attempt. Exact captured public metadata is evidence, not proof of write access or deposition identity. A future API rejection does not justify another endpoint, altered permission or weaker label. Reissue bundles contain provisional sealed manuscripts and historical audit material; they are prepared for review and cannot be treated as approved public manuscripts.

Potential schema or permission differences must be resolved with authenticated GET and the current documented API before any mutation. Current metadata includes server-managed DOI, resource type and version relations; those are retained in before snapshots and omitted/mapped only to documented deposition write fields in proposed payloads.
