\begin{abstract}
We isolate the smallest deterministic model of error cancellation in a
two-member cognitive ensemble. For supplied scalar errors $e_1,e_2$ relative
to one fixed target, a convex pool has error
$E(w)=w e_1+(1-w)e_2$. If $e_1=-a$, $e_2=b$, and $a,b>0$, then the unique
zero-error weight is $w^*=b/(a+b)\in(0,1)$. If both errors share a weak sign,
every convex pool preserves that sign, so averaging alone cannot cancel a
common directional error. Exact-rational tests support the identities; the eight named Lean declarations now have exact-hash private dual-kernel
Comparator certification. This is a methods note, not a probability-
calibration theorem, empirical cognitive model, or alignment guarantee.
\end{abstract}

\section{Introduction and prior work}
Combining forecasts and model outputs is a mature practice, often robust even
when simple rules are used \cite{clemen1989}. Yet a combined forecast does not
inherit every desirable property of its inputs: in particular, linear pools of
probability forecasts can lose calibration and sharpness \cite{gneiting2010}.
Recent ensemble theory likewise makes improvement depend on the loss and model
regime rather than on plurality alone \cite{mattei2025}.

We ask a smaller audit question for a scalar target already observed: when can
a convex combination cancel two supplied signed errors? The answer is elementary
but useful as a boundary statement. It does not estimate errors before the
target is known, address probabilistic calibration, or imply that disagreement
is beneficial under distribution shift.

Earlier Viridis Cognitive Modeling work studied precision control (Run 108) and
switching hysteresis (Run 131). Run 111 studied common-mode calibration gauge
freedom in networks. The present object is only a static two-error pool and does
not reuse those mechanisms. Novelty and significance remain unassessed.

\section{Model and preregistered claims}
Let a fixed scalar target be $y$, and let two supplied estimates have signed
errors $e_1=\hat y_1-y$ and $e_2=\hat y_2-y$. For $w\in[0,1]$, define
\begin{equation}
 E(w)=w e_1+(1-w)e_2. \label{eq:pool}
\end{equation}
The endpoints recover the constituent errors: $E(0)=e_2$ and $E(1)=e_1$.

\paragraph{Proposition 1 (opposite-sign cancellation).}
Suppose $e_1=-a$, $e_2=b$, and $a,b>0$. Then
\begin{equation}
 w^*=\frac{b}{a+b}\in(0,1), \qquad E(w^*)=0. \label{eq:cancel}
\end{equation}
Indeed, $w^*a=(1-w^*)b$. Positivity of $a$ and $b$ makes the weight interior.
For $a=2$ and $b=3$, $w^*=3/5$ and
$(3/5)(-2)+(2/5)3=0$, establishing a nonempty instance.

\paragraph{Proposition 2 (shared-sign persistence).}
If $e_1,e_2\geq0$, then $E(w)\geq0$ for all $w\in[0,1]$. If
$e_1,e_2\leq0$, then $E(w)\leq0$. Thus exact cancellation in the interior
requires zero to lie between the two supplied errors; adding a second estimate
with the same directional error is not sufficient.

\paragraph{Proposition 3 (scale and symmetry bookkeeping).}
Scaling both errors by the same scalar scales $E(w)$ by that scalar, while
swapping model labels and replacing $w$ by $1-w$ leaves the pooled error
unchanged. These are bookkeeping invariances, not claims about generalization.

\section{Discussion, falsification, and limitations}
Equation~\eqref{eq:cancel} is retrospective bookkeeping. Using it prospectively
would require evidence that the errors and target relation remain stable, an
estimation protocol that does not leak the outcome, uncertainty and dependence
models, and a decision loss. If the target is unknown, ``opposite signs'' is not
an observable fact without additional calibration. Correlated or strategically
reported errors can make a cancellation rule fragile.

The note excludes vector-valued targets, nonlinear pools, changing weights,
probability calibration, sharpness, selective prediction, causal cognition,
human behavior, adversarial models, and distribution shift. It is falsified by
an exact-rational counterexample under its assumptions or any paper-to-Lean
statement mismatch. No empirical dataset, production model, customer system,
or ecological decision process was analyzed.
