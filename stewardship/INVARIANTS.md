# Information-weighted stewardship: invariant-to-test map

Recorded before implementation. This is a review candidate, not admitted science.
Scope: locally absolutely continuous D:[0,∞)→[0,K], measurable H,
0≤H≤ΩD almost everywhere, D′=g(D)−φH almost everywhere, D(0)=D*.
The theorem quantifies over already-admissible trajectories; general controlled-ODE
existence/state invariance is a separate claim. Positive α,K,φ,Ω,r; r<2α;
Ω≥(α+r)/(3φ). Stock continuity is required for equality at every time.

| Invariant | Planned evidence / regression |
|---|---|
| Same initial state, dynamics, channel, constraints, discount, horizon and terminal treatment | Matched-policy benchmark inputs; reject mismatched head-to-head comparisons |
| Attempts, fresh predictive bits, retained bits, physical erasure, power are distinct | Channel enumeration, unique target IDs, units table, energy bridge assumptions |
| Sustained rate is g(D*)/φ, not ΩD* | Nonunit K/φ tests; balance and cap-equality checks |
| Actual lifetime integral includes transient and terminal terms | Independent ODE objective integration vs potential identity; finite-horizon reversal; analytic tail bound |
| Policy class and initial state are unchanged in full theorem | Explicit formal-status map; no C1 or accounting-hypothesis lemma advertised as full AC result |
| No holes, assumed conclusions, inconsistent hypotheses, weakened checks, invented runs | Enforcing axiom audit, nonvacuous witnesses, exact command logs |
| Symbolic, compiled, numerical, physical and novelty evidence remain separate | Machine-readable evidence class; no new empirical/priority claim |
| Existing proof environments and historical releases preserved | Baseline current and P0 checks; pinned toolchains unchanged; explicit compatibility aliases and errata |
| Out-of-scope inputs cannot yield an interior optimal-policy claim | r=0, r≥2α, insufficient Ω rejected; φ=0 separate dynamics |
| Arbitrary initial stock retains transition cost | Only potential upper bound outside D0=D* |
| Constant-quality comparison has its own admissible starting stock | Raw certificate at D_raw, Ω≥(α+r)/(2φ); matched comparisons within experiment |
| Numerical validity is checked rather than enforced by clipping | Overshoot and inadmissibility rejection; independent objective and regret integrals |
